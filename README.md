# Python_Bloomsburg_2026

Personal coursework repository for my Python class at Bloomsburg Commonwealth University.

## What's in here

This repo contains my own solutions to class assignments, including in-progress work, mistakes, and incomplete attempts — not just polished final answers. Each assignment folder includes the problem instructions alongside my solution so the context is preserved.

Note: the early part of this course (and, as of this update, currently) uses Pyret, an analog language designed to aid the learning of Python. As such, some content here is written in Pyret. This does not reflect any personal opinion on the language or its use as a learning aid — my opinions on that are my own and irrelevant to the purposes of this repo.

## Purpose

This repository exists so I can:
- Track my own progress and revisit earlier work
- Reference past solutions when working on later assignments
- Share my process (including where I went wrong) for anyone learning the same material

## Usage

This code is shared for **reference and learning purposes only**. It is **not intended for academic plagiarism** — if you're taking a similar course, use this to understand approaches and debug your own thinking, not to copy submissions. Submitting this work as your own would violate most academic integrity policies (and defeats the point of taking the class).
